This note is a cheat sheet for writing on this site. It's marked `draft: true`, so it only shows up when you run the site locally.

## The basics

Every note is an `.mdx` file in `content/notes`. The file name becomes the URL. At the top goes the frontmatter:

```yaml
---
title: My note
date: 2026-09-24
description: One line for the list.
category: Thoughts
accent: "#e8b04b"   # optional
draft: true         # optional
---
```

Categories are made up on the fly. Use a new one and it appears as a filter on the notes page. The `accent` colour tints links, highlights and scribbles in that note only, so each note can have its own mood while the layout stays the same.

Regular markdown works: **bold**, _italic_, [links](https://example.com), lists, `code`, tables and quotes.
